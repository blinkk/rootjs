# 🌱 Root.js

> Root.js is a web development framework with a built-in CMS, designed for building modern, performant web applications.

- 🛠️ TSX Rendering
- 🕸️ Web Components
- 📁 File Routes
- 🇯🇵 i18n
- 📇 CMS
- 🤖 AI

[Read the Docs to Learn More](https://rootjs.dev)
